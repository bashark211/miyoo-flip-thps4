# Contributing

Keep a known-working checkpoint before experiments. Report the exact source
revisions, hardware/firmware, game executable hash (not the executable), test
scene, clock/temperature, frame timing and graphics/save correctness.

A material probe passing is necessary evidence for some changes, but not a
replacement for actual game presentation and save validation. Label hypotheses,
player impressions and measured results separately. Keep failures documented.

Do not upload proprietary game files, activation material, personal prefixes,
saves, credentials or unreviewed raw memory/perf dumps. Original project scripts
and documentation use MIT; respect the separate upstream component licenses.
